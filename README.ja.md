# Sw7

心理学。システム。意図のある自動化。

[English](README.md) · [Português](README.pt-BR.md) · [日本語](README.ja.md)

ブラジルのリベイラン・プレトを拠点とする心理士です。人への理解を、より明確なワークフローとシステム設計に生かす方法を探究しています。

## 主なプロジェクト

| プロジェクト | 主な内容 |
| --- | --- |
| [arkham](https://github.com/ncaio632/arkham) | 位置情報と参加条件に基づく登録設計。 |
| [gotham](https://github.com/ncaio632/gotham) | 案件の背景、証拠、レビューしたサポート回答。 |
| [pegasus](https://github.com/ncaio632/pegasus) | カタログの正確性と問い合わせ意図の計測。 |
| [snowflake](https://github.com/ncaio632/snowflake) | 追跡可能な期間、集計、業務レポート。 |
| [white-fluffy](https://github.com/ncaio632/white-fluffy) | 連携ツールの機能確認と権限の境界。 |
| [manhattan](https://github.com/ncaio632/manhattan) | 検証済みスナップショット、ローカル同期、復旧設計。 |

公開リポジトリには、エンジニアリング仕様、合成サンプルの契約、レビュー可能な実装計画をまとめています。

## 取り組み方

背景を理解する。境界を定める。判断の理由を示す。結果を主張する前に確認する。
